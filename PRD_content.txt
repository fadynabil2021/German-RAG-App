1. Executive Summary
The German RAG App is an AI-powered German language learning SaaS platform built on FastAPI (Python), Next.js (TypeScript), PostgreSQL with pgvector, Celery/RabbitMQ, Redis, and Qdrant. A comprehensive automated code review dated May 12, 2026 revealed that the repository is in an undeployable state: all 10 recent CI/CD pipeline runs have failed, and multiple foundational files are absent entirely.
This PRD defines the complete scope of work required to (a) remediate every identified bug and configuration defect, (b) replace the Kubernetes-centric deployment with a leaner Vercel + Render cloud stack suitable for a SaaS MVP, and (c) establish a reliable CI/CD pipeline that gates every merge on green tests.

5.7 FR-07 — Per-User Rate Limiting
# security/rate_limit.py
LIMITS = {"free": int(settings.RATE_LIMIT_PER_MINUTE_FREE),
          "pro":  int(settings.RATE_LIMIT_PER_MINUTE_PRO)}
async def check_rate(user_id: str, tier: str, redis: Redis):
    key = f"rl:{user_id}:{int(time.time())//60}"
    count = await redis.incr(key)
    if count == 1: await redis.expire(key, 65)
    if count > LIMITS[tier]: raise HTTPException(429)

6. CI/CD Pipeline — GitHub Actions
6.1 Pipeline Overview
The redesigned pipeline follows a strict quality gate model: no stage proceeds if a prior stage fails. The deploy stage only runs on pushes to main.
┌──────────┐   ┌───────────┐   ┌──────────────┐   ┌───────────────────┐
│ lint     │──▶│ test      │──▶│ build-images │──▶│ deploy            │
│ flake8   │   │ pytest    │   │ backend:sha  │   │ Render deploy hook│
│ black    │   │ asyncio   │   │ frontend:sha │   │ Vercel CLI push   │
│ mypy     │   │ ≥70% cov  │   │ push to GHCR │   │ smoke test /health│
└──────────┘   └───────────┘   └──────────────┘   └───────────────────┘
6.2 Full Workflow File — .github/workflows/ci-cd.yml
name: G-RAG CI/CD Pipeline
on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]
env:
  REGISTRY: ghcr.io
  IMAGE_BACKEND: ghcr.io/${{ github.repository }}/backend
  IMAGE_FRONTEND: ghcr.io/${{ github.repository }}/frontend
  PYTHON_VERSION: "3.11"
  NODE_VERSION: "18"
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "${{ env.PYTHON_VERSION }}" }
      - run: pip install flake8 black mypy
      - run: flake8 src --count --select=E9,F63,F7,F82 --max-line-length=120
      - run: black --check src
      - run: mypy src --ignore-missing-imports
  test:
    needs: lint
    runs-on: ubuntu-latest
    services:
      postgres:
        image: pgvector/pgvector:0.7.0-pg16
        env: { POSTGRES_PASSWORD: test, POSTGRES_DB: grag_test }
        options: >-
          --health-cmd "pg_isready -U postgres"
          --health-interval 5s --health-retries 10
        ports: ["5432:5432"]
      redis:
        image: redis:7-alpine
        ports: ["6379:6379"]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "${{ env.PYTHON_VERSION }}" }
      - run: pip install -r src/requirements.txt
      - run: cd src && pytest tests/ -v --cov=. --cov-report=xml --cov-fail-under=70
        env:
          DATABASE_URL: postgresql+asyncpg://postgres:test@localhost:5432/grag_test
          REDIS_URL: redis://localhost:6379/0
          APP_SECRET_KEY: ci-test-secret
          GENERATION_BACKEND: openai
          OPENAI_API_KEY: sk-test
  build-backend:
    needs: test
    runs-on: ubuntu-latest
    if: github.event_name == 'push'
    permissions: { contents: read, packages: write }
    steps:
      - uses: actions/checkout@v4
      - uses: docker/login-action@v3
        with: { registry: ghcr.io, username: ${{ github.actor }},
                password: ${{ secrets.GITHUB_TOKEN }} }
      - uses: docker/build-push-action@v5
        with:
          context: .
          file: docker/minirag/Dockerfile
          push: true
          tags: ${{ env.IMAGE_BACKEND }}:${{ github.sha }},${{ env.IMAGE_BACKEND }}:latest
  build-frontend:
    needs: test
    runs-on: ubuntu-latest
    if: github.event_name == 'push'
    permissions: { contents: read, packages: write }
    steps:
      - uses: actions/checkout@v4
      - uses: docker/login-action@v3
        with: { registry: ghcr.io, username: ${{ github.actor }},
                password: ${{ secrets.GITHUB_TOKEN }} }
      - uses: docker/build-push-action@v5
        with:
          context: frontend
          file: frontend/Dockerfile
          push: true
          tags: ${{ env.IMAGE_FRONTEND }}:${{ github.sha }},${{ env.IMAGE_FRONTEND }}:latest
  deploy:
    needs: [build-backend, build-frontend]
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps:
      - name: Trigger Render deploy (backend)
        run: |
          curl -s -X POST "${{ secrets.RENDER_DEPLOY_HOOK_BACKEND }}"
      - name: Deploy frontend to Vercel
        uses: amondnet/vercel-action@v25
        with:
          vercel-token: ${{ secrets.VERCEL_TOKEN }}
          vercel-org-id: ${{ secrets.VERCEL_ORG_ID }}
          vercel-project-id: ${{ secrets.VERCEL_PROJECT_ID }}
          vercel-args: '--prod'
      - name: Smoke test
        run: |
          sleep 30
          curl -f ${{ secrets.BACKEND_URL }}/health || exit 1
